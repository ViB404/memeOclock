# MemeOClock 🤖

**Discord Meme Bot** — Automatically sends a fresh meme every hour in your server.

Built with **TypeScript** and **Bun** — Fast, lightweight, and simple.

---

### Features
- Sends one fresh meme every hour automatically  
- Uses Reddit memes only (for now)  
- Clean and minimal — no unnecessary spam  
- Easy to setup and run

---

### Requirements
- Bun 1.0 or newer

---

### 🚀 Getting Started

```bash
git clone https://github.com/ViB404/memeOclock.git
cd memeOclock
bun install
```

---

### ⚙️ Configuration

Copy `.env.example` to `.env` and add your bot token:

```env
BOT_TOKEN=your_bot_token_here
```

> ⚠️ Never share your bot token publicly.
